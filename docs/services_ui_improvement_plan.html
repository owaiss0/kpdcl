Services Page UI & Layout Overhaul Plan

Detailed architectural & interface enhancement plan for Kashmir Power Distribution Corporation Limited (KPDCL) Consumer Services Portal.

Design Guidelines Alignment: Built with Nova style, neutral base color, blue brand theme, green chart accent tokens, Inter typography, and Lucide icons. Complies with strict sandbox and Next.js 16 App Router standards.

1. Current Limitations & Identified Deficiencies

  • Monolithic Grid with Zero Filtering: 6 cards scattered in a flat grid with no categorisation (Personal, Technical, Green Solar, Grievances).
  • Cramped Modal Dialogs: Complex multi-field forms (Load change, Solar Net Metering) crammed in generic popups without stepper guidance or visual context.
  • Static Document Badges: Documents list had dead button icons with no file picking, file size check, preview, or remove functionality.
  • Non-interactive Ticket Tracking: Ticket table was completely passive; no search, no status filtering, and clicking rows did nothing.
  • Lack of Emergency & Escalation Information: Missing KPDCL 1912 24x7 helpline, grievance escalation matrix (JE → SDO → XEN → SE), and SLA turnaround times.

2. Target Architecture & Layout Structure

Header & Live Status Banner Enhanced

Displays consumer connection summary, active requests counter, average resolution turnaround (SLA), and 24x7 KPDCL emergency helpline widget (1912).

Tabbed Service Navigation New

Organised into 3 clear operational views: Explore & Apply, Track Applications & Tickets, and Offline Forms & Guidelines.

Interactive Service Catalog Enhanced

Search filter, category pill selectors (Ownership, Load & Tariff, Solar, Grievance), SLA estimates, fee badges, and requirements counter on each card.

Interactive File Uploader New

Upload dropzone simulation with file attachment, realistic file name & size preview, validation indicators, and removal action.

3. Interactive Features & Workflow Specifications

Module Features Added UX Impact
Service Cards Turnaround SLA badges, fee indicators, category pill filters, real-time search Quick discovery of relevant citizen services
Form Modals Current connection summary card, interactive input validation, file uploader Frictionless submission process with clear requirements
Submission Feedback Instant confirmation modal with generated Reference/Ticket ID and next steps Transparency and immediate proof of application submission
Ticket Lifecycle Tracker Interactive tracking dialog with 4-stage visual timeline and field officer remarks Consumer empowerment without physical sub-division visits
Support & Escalation Official KPDCL grievance hierarchy, 1912 helpline, smart meter support numbers Seamless resolution escalation for urgent power issues

4. Implementation Step Checklist

  1. Plan Documentation: Generate comprehensive HTML implementation specification in docs/services_ui_improvement_plan.html.
  2. Redesign app/services/page.tsx:
    • Implement contextual metrics header (Active Connection, Open Tickets, SLA, 24x7 Helpline).
    • Add 3 primary tabs: Catalog, Ticket Tracker, and Help & Guidelines.
    • Implement category filter pills and live search bar.
    • Enrich service cards with metadata (TAT, fees, docs required).
    • Enhance application forms with interactive document uploader and current details preview.
    • Implement submission confirmation modal with generated application ID.
    • Upgrade Ticket Tracking with search, status filters, and interactive 4-stage timeline modal.
  3. Quality Verification: Verify TypeScript types, responsive breakpoints (mobile, tablet, desktop), and adhere strictly to user constraints.
