Features & Pages

Pages

PageRouteDescription
Home / Hero section with consumer number input. Quick stats (bill due, outage status). Footer with helpline numbers.
Bill Detail /bill-payment Shows current bill (amount, due date, status). Consumer info summary. "Pay Now" button that opens payment modal.
Payment /bill-payment?pay=billId Payment confirmation modal. Shows amount, consumer name. Mock payment methods (UPI, net banking, card). Success / failure screen.
History /history Table of past bills with status badges. Sort by date, filter by status. Click row to expand details.

Data Flow

  1. User enters consumer number on Home page
  2. ConsumerLookup calls fetchConsumerByNo(no) from data/demo.ts
  3. On match, redirect to /bill-payment?consumer=xxx
  4. BillDetailPage calls fetchCurrentBill(consumerNo)
  5. User clicks "Pay Now" → PaymentModal opens
  6. User confirms → submitPayment(billId, amount) called
  7. On success, redirect to history or show receipt

Full Feature Set (After Login)

Sidebar Navigation

  • Dashboard
  • Usage
  • Net Meter
  • Billing
  • Services
  • Documents
  • Profile

Dashboard

  • Header: "Welcome, {Consumer Name}" on right, "PREPAID" badge
  • Consumer Info Card: Name, Consumer ID, Consumer Category (PREPAID), Meter Serial No, Account ID, Mobile Number, Email
  • Payment Pending Card: Shows pending amount with "Recharge" and "View Bill" buttons
  • Recent Payments Card: List of recent payments
  • Charts: Bar chart + line chart showing recent payments in different sections

Usage

  • Filters: Hourly / Daily / Monthly / Weekly / Yearly (default: Daily)
  • Date range picker — view past month or full month with next/expand
  • Consumer filter dropdown
  • Graph: Usage chart above table based on selected filter
  • Table columns: Date, Unit Consumed, Opening Read, Closing Read
  • Export: CSV, PDF, Excel

Net Meter Separate sidebar item

  • Same filters as Usage: Hourly / Daily / Monthly / Weekly / Yearly
  • Graph: Net meter usage chart
  • Table columns: Date, Start Imp., End Imp., Total Imp., Start Exp., End Exp., Total Exp., Net Usage
  • Export: CSV, PDF, Excel

Billing

  • Table columns: Date, Transaction ID, Transaction Type, Transaction Amount, Available Balance
  • Filters: Date range (shadcn date picker), transaction type filter
  • Combined Graph: Recent transactions vs recharge history vs revenue balance over time (all on one chart)
  • Export: CSV, PDF, Excel

Services

  • Name Change — current name (read-only) → new name + reason
  • Ownership Change — current owner info → new owner name, relationship, ID proof
  • Category Change — current category → dropdown (Domestic/Commercial/Industrial)
  • Load Change — current sanctioned load → requested kW + reason
  • Solar Agreement — type (new/net-meter/modify), capacity, installer/vendor
  • Raise / Track Ticket — type (complaint/query/request), subject, description, attachment
  • Recent Tickets table — ticket ID, subject, date, priority, status badges
  • All services open as modals from a grid of service cards

User Profile

  • Consumer ID, Installation Number, Name, Category (Domestic/Commercial/Industrial)
  • Parentage, Service Agreement ID, PREPAID/Account ID
  • Service Start Date, Meter Batch, Meter Serial Number
  • Sanction Load (kW), Phone, Feeder Code, Email
  • Read-only display of all consumer details

Documents

  • No Dues Certificate — view & download
  • Bill Print — view & download past bill PDFs
  • Document list with date, type, download button
