export async function fetchCurrentBill(consumerNo: string): Promise<Bill | null> {
  // DEMO: return mock data
  // REAL: return fetch(`/api/bills/current/${consumerNo}`).then(r => r.json())

export async function fetchBillHistory(consumerNo: string): Promise<Bill[]> {

Key principle: Every async function has // DEMO and // REAL comments. To go live, replace the function body. Zero changes in components or pages.

Design System

  • UI: shadcn/ui components (button, card, table, dialog, badge, input)
  • Styling: Tailwind CSS
  • Icons: Lucide React
  • Colors: Blue theme (matching KPDCL brand)
  • Font: Inter

Swapping Demo → Real Data

Three approaches (choose one):

  1. Direct swap: Replace function bodies in data/demo.ts with real fetch() calls
  2. Two files: Keep demo.ts for dev, create api.ts for production — change imports
  3. Env-driven: Create services/bill-service.ts that picks source based on NEXT_PUBLIC_USE_DEMO env var
